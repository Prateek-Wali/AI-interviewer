# 🚨 READ BEFORE CODING: Team Rules 🚨

Until our GitHub Student Pack is active, we are on the **"Honor System."** Please follow these rules strictly to avoid breaking the app.

### 1. The Golden Rule
**NEVER push code directly to `main`.**
* 🛑 `git push origin main` = FORBIDDEN.
* ✅ `git push origin feature/my-new-feature` = GOOD.

### 2. Workflow
1.  **Start:** Always pull the latest updates first: `git pull origin main`
2.  **Branch:** Create a new branch for every task: `git checkout -b feature/name-of-task`
3.  **Push:** Push your branch: `git push -u origin feature/name-of-task`

### 3. Merging (The Safety Check)
Since we don't have automatic branch protection yet:
1.  Create a **Pull Request (PR)** on GitHub.
2.  **DO NOT MERGE** your own PR until you have texted the other person.
3.  Wait for a verbal/text "Approved" before clicking the green Merge button.

---
*If you mess up and push to main, STOP and message me immediately.*
